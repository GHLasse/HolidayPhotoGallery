# v0.1: points to test over time

Lasse tested v0.1 on prep up to 2026-11-05. These points could not be tried properly in a short test and are
watched in everyday use. Report anything odd in the project thread; fixes go into the next experimental build.

| Area | What to watch | Why it is still open |
|---|---|---|
| G-4 GPS tracks | Placing photos from a Google Maps Timeline (red dots on the track, Assign). Track rename and "Show on the map" (fixed in #105/#106). | Timeline import works; no trip with photos and a matching track yet. |
| G-3 Location estimate | How close the estimate from the photos before and after is. | Hard to judge without tracks or reference lines. |
| M-6 Saving on a shared drive | Two people (or two PCs) changing the same photo; only real clashes should get a banner. | Skipped: needs a NAS or a second PC. |
| C-4 Similar shots | Stacks on real trips: bursts stacked, different views kept apart; old stacks corrected. | Tightened in #98/#100; few real bursts tested. |
| C-4b Quality hints | Hint icons on blurry, dark or bright photos; gone once rated or ignored. | New in #94; needs many real photos. |
| AL-1 Albums | Renaming an album: the name updates in the app; Google Photos album name; OneDrive. | Cloud rename only partly tested; OneDrive not tested. |
| F-2 Batch rename | The counter length follows the number of photos. | Noted as not adjusting. |
| M-5 Tag trees | Upper levels in the filter; clicking a level in the info pane filters by that level. | Noted on 2026-10-31. |
| Save queue (#101) | Editing many photos quickly: every change saved, undo per change, closing the app waits for saves. | New; needs long editing sessions. |
| Background jobs (#103/#104) | Faces, auto-tags, fingerprints, quality, file checks and place names keep up during a long session and after edits in other apps, including while the app was closed. | Needs days of use. |
| Background place names (#100/#103) | Settings › Dates and places count goes down; no repeated lookups. | Needs a library with GPS photos without place names. |
| Auto-tagging (#100) | "New photos and the ones I already have" never starts again from the beginning. | Needs several imports over time. |
| Rotation | Animated GIF rotation; animated WebP rotate buttons fade with a hint. | Not tried on Windows. |
| Updates | The update check shows the version found ("Update to 0.1.N"). | Fixed in #107. |
